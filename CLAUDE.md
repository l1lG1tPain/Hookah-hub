# Инструкции для агентов (Hookah Hub)

1. **Перед любой задачей прочитайте `ARCHITECTURE.md`**: там стек, структура, маршруты, схема БД, RPC,
   потоки авторизации, дизайн-система и подводные камни. Не исследуйте код с нуля.
2. **После изменений, которые затрагивают описанное в `ARCHITECTURE.md`** (маршруты, таблицы/RPC/миграции,
   env, авторизация, ключевые механики UI, дизайн-токены), обновите соответствующий раздел и дату в шапке.
3. **Синхронизируйте `ARCHITECTURE.md` с claude.ai Project «Hookah hub»**, если в сессии есть инструмент Projects:
   `project_write` с `path: "claude/ARCHITECTURE.md"` (существующий документ заменяется). Делайте это только при реальных изменениях.
4. Язык интерфейса и общения — русский. Стиль: тёплый тёмный «Ember Lounge», **без стекла и blur**.
5. Схему БД меняйте только идемпотентными SQL-файлами в `supabase/migrations/`. Изменения в рабочей базе
   подтверждает пользователь.
6. Пользовательские данные выводите только через `html\`\`` из `src/lib/ui.js` (автоэкранирование).
